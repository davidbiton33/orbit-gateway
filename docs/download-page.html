גישה מרחוק לפאנל עם Tailscale

רוצים להיכנס ל־Orbit מהנייד, מהמשרד או ממחשב אחר? מחברים את המכשירים ל־Tailscale ומפעילים Serve פרטי. הפאנל נשאר על המחשב שלכם; אין צורך לפתוח פורטים בנתב.

1

מתקינים Tailscale

מתקינים על מחשב Windows שמפעיל את Orbit וגם על המכשיר שממנו תיגשו. מתחברים לאותו Tailnet.

אתר ההורדה הרשמי של Tailscale

winget install --id Tailscale.Tailscale --exact
2

מפעילים גישה פרטית

מפעילים Orbit פעם אחת ליצירת קובץ .env. בתיקיית Orbit פותחים PowerShell ומריצים את הסקריפט המצורף.

powershell -ExecutionPolicy Bypass -File .\ENABLE-TAILSCALE.ps1

הסקריפט מזהה את שם המחשב ב־Tailnet ומגדיר HTTPS ל־Studio, בלי Tailscale Funnel.

3

מפעילים מחדש ומתחברים

סוגרים ומפעילים מחדש את Orbit אחרי ההגדרה. במכשיר המרוחק פותחים את כתובת ה־HTTPS שהודפסה בפלט הסקריפט.

https://your-pc.your-tailnet.ts.net/

זו דוגמה בלבד. הכתובת האישית שלכם מתקבלת אוטומטית מ־Tailscale.

גם API מרחוק, פקודות בדיקה וכיבוי הגישה
גישה גם ל־API בסוכנים וב־Thunder Client

אפשר להריץ את הסקריפט עם הפרמטר הבא:

powershell -ExecutionPolicy Bypass -File .\ENABLE-TAILSCALE.ps1 -ExposeApi

כתובת ה־API תהיה https://your-pc.your-tailnet.ts.net:8443/v1, עם Bearer Token מקובץ .env המקומי.

סטטוס וביטול
tailscale status
tailscale serve status
powershell -ExecutionPolicy Bypass -File .\DISABLE-TAILSCALE.ps1

Serve במצב רקע ממשיך להיות מוגדר עד שמכבים אותו; Orbit עצמו חייב להישאר פועל במחשב.

הגדרה ידנית של Serve
tailscale serve --bg --https=443 http://127.0.0.1:5283
tailscale serve --bg --https=8443 http://127.0.0.1:5284

הפקודות הידניות לבדן אינן מגדירות ORBIT_REMOTE_STUDIO_HOST. לכן יש להריץ פעם אחת את סקריפט ENABLE-TAILSCALE.ps1. פורט 8443 מיועד ל־API בלבד.

חשוב לאבטחה: Studio אינו דורש סיסמה נוספת. מכשירים עם הרשאת גישה בתוך ה־Tailnet יכולים להפעיל את חשבונות ה־AI המחוברים. הגבל הרשאות עם Tailscale ACL/Grants והשתמש רק במכשירים מהימנים. לא להשתמש ב־Tailscale Funnel — הוא חושף שירותים לאינטרנט הציבורי. ייתכן שיהיה צורך להפעיל אישורי HTTPS בהגדרות Tailscale.

שאלות נפוצות

זה באמת בחינם?

Orbit עצמו חינמי לניסיון ואינו גובה תשלום. כל ספק AI כפוף למנוי, למכסות ולתנאי השימוש שלו. ההתקנה צורכת משאבים מקומיים.

אני צריך לתת למישהו את הסיסמה שלי?

לא. ההתחברות לחשבונות AI נעשית ידנית בדפדפן המקומי של Orbit. אל תעבירו לאף אחד סיסמאות, עוגיות, קובצי .env או Tokens.

האם AI Mode יוצר תמונות?

כן, יצירת תמונה נבדקה מקצה לקצה בשרת Oracle של המפתח. בכל התקנת Windows נדרש קודם להתחבר ל־Gemini; התמיכה תלויה גם בממשק Google, במיקום ובמכסת החשבון. עריכת תמונות ב־AI Mode אינה נתמכת עדיין.

האם זה API רשמי?

לא. Orbit מפעיל ממשקי דפדפן באמצעות אוטומציה ומציג API מקומי אחיד. שינוי בממשק הספק, דרישת אימות או הגבלות חשבון עלולים להשפיע על השירות.

איך בודקים את ה־API?

בתוך Studio, בלשונית API, יש קוד להעתקה והנחיות לסוכן. הבסיס המקומי הוא http://127.0.0.1:5284/v1 ויש לצרף Bearer Token מקובץ .env המקומי.
