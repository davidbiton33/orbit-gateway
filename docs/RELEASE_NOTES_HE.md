- `login-native.sh` שומר הודעות Chrome הטכניות לקובץ לוג במקום להציף את PowerShell.
- הודעת שימוש ברורה: סגירת כל חלונות Chrome מסיימת את הפקודה; סגירת טאב בלבד אינה מספיקה בהכרח.
- עם יציאה תקינה של Chrome מתקבלת הודעת סיום, והפרופיל נשאר ב־Volume.

- סיום סקריפט אינו מבטיח התחברות מוצלחת — מאמתים ב־Studio.

# Orbit Gateway 2.1.1 — תיקון Clean Install (25.10.2026)

מנועי הצ'אט נשמרו מ־2.1.0; השינויים נמצאים בשכבת הפריסה והתחברות משתמש ראשון.

1. אין שם Compose קבוע; כל התקנה נרשמת עם מזהה אקראי ו־Volumes משלה.
2. ניתוק מוחלט של GPT Legacy מ־`unified-ai-gateway_gpt_browser_profile`.
3. CleanTest עצמאי בתיקייה נפרדת ובפורטים נפרדים, המאפשר בדיקה תוך השארת הגרסה הישנה פועלת.
4. בדיקת בידוד Containers/Volumes באמצעות `verify-clean.ps1`.
5. Legacy Login מתבצע דרך Chrome שכבר רץ ב־noVNC, ללא סקריפט Login שמתנגש בפרופיל פעיל.
6. מדריכי התקנה ותחזוקה מותאמים למסלול החדש.

החבילה אינה כוללת התחברויות משתמש ו־Cookies. בדיקת Chrome/Google/Claude/ChatGPT חיה נדרשת עדיין.
