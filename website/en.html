Get started in three steps

No Docker or separate server required. Some comfort with developer tools is recommended.

1

Install Node.js

Get version 22 or later from the official Node.js site.

2

Extract and launch

Extract the ZIP into a permanent folder. Open PowerShell in that folder and run:

powershell -ExecutionPolicy Bypass -File .\START-WINDOWS.ps1
3

Open Orbit

Go to 127.0.0.1:5283 and sign into your AI accounts manually using Orbit's browser. Chromium installs on first launch.

Security: The local API listens on http://127.0.0.1:5284/v1 and requires a per-installation Bearer token. Never share your .env or data directory. Antivirus warnings can occur during PowerShell or Chromium installation; verify the source and don't bypass warnings you don't understand.

API examples you can copy

Start Orbit and sign in to a provider first. Use the token generated in your local .env file; replace YOUR_ORBIT_TOKEN and never share the real token.

List available models

curl -H "Authorization: Bearer YOUR_ORBIT_TOKEN" http://127.0.0.1:5284/v1/models

Chat completion

curl -X POST http://127.0.0.1:5284/v1/chat/completions -H "Authorization: Bearer YOUR_ORBIT_TOKEN" -H "Content-Type: application/json" -d '{"model":"gemini","messages":[{"role":"user","content":"Explain Orbit Gateway in one sentence"}]}'

Generate an image

curl -X POST http://127.0.0.1:5284/v1/images/generations -H "Authorization: Bearer YOUR_ORBIT_TOKEN" -H "Content-Type: application/json" -d '{"model":"gemini","prompt":"A futuristic city at sunset","aspect_ratio":"16:9","response_format":"b64_json"}'

Provider capabilities

curl -H "Authorization: Bearer YOUR_ORBIT_TOKEN" http://127.0.0.1:5284/v1/capabilities

The examples use curl syntax (Bash, Git Bash or curl.exe on Windows). Browser-backed providers can be slow or temporarily unavailable. The default aliases (such as gemini) do not guarantee an exact model version. Full API specification

Private remote access with Tailscale

Access Orbit from your phone or another computer through your private Tailscale network. No router ports need to be opened.

1

Install Tailscale

Install it on the Windows computer running Orbit and on your remote device. Sign both in to the same Tailnet.

Official Tailscale download

winget install --id Tailscale.Tailscale --exact
2

Enable private access

Launch Orbit once to generate .env, then run this script from its folder:

powershell -ExecutionPolicy Bypass -File .\ENABLE-TAILSCALE.ps1

The script configures private HTTPS access to Studio; it does not enable public Funnel.

3

Restart and connect

Restart Orbit and open the HTTPS URL printed by the script on your remote device.

https://your-pc.your-tailnet.ts.net/

This is only an example; Tailscale prints your actual address.

Remote API access, status and shutdown
Expose the authenticated API as well
powershell -ExecutionPolicy Bypass -File .\ENABLE-TAILSCALE.ps1 -ExposeApi

API URL: https://your-pc.your-tailnet.ts.net:8443/v1, secured by the local .env Bearer token.

Check or disable access
tailscale status
tailscale serve status
powershell -ExecutionPolicy Bypass -File .\DISABLE-TAILSCALE.ps1

Tailscale Serve configuration persists until disabled; Orbit must remain running.

Manual Serve configuration
tailscale serve --bg --https=443 http://127.0.0.1:5283
tailscale serve --bg --https=8443 http://127.0.0.1:5284

Run ENABLE-TAILSCALE.ps1 at least once to set ORBIT_REMOTE_STUDIO_HOST. Port 8443 is for the API.

Important: Studio has no separate password. Tailnet devices with access may use connected AI accounts. Restrict access using Tailscale ACLs/Grants and trusted devices. Do not use Tailscale Funnel, which exposes services publicly. HTTPS certificate setup may be required in Tailscale.

Frequently asked questions

Is it really free?

Orbit is free to try and has no Orbit usage fee. Your AI subscriptions, provider quotas and terms still apply. Local system resources are used.

Do I give Orbit my password?

You sign in manually through the local browser. Never share passwords, browser cookies, .env files or tokens.

Can AI Mode create images?

Image generation was verified end-to-end on the developer's Oracle host. New Windows installations need their own Gemini login. Availability depends on Google's interface, location and account quota. AI Mode image editing is not currently supported.

Is this an official provider API?

No. Orbit automates browser interfaces and exposes a local unified API. Provider UI changes, verification challenges or account restrictions can disrupt it.

How do I test the API?

Use the Studio API tab or the examples above. The API base URL is http://127.0.0.1:5284/v1, with Bearer authorization from the locally generated .env.
